# 安全模型

- 本工具以当前用户权限运行。权限策略、路径检查和 Worktree 不是操作系统沙箱。
- Shell 黑名单无法证明任意命令安全；只在可信仓库使用，逐次审查副作用授权。
- MCP 默认 HTTPS、禁止自动重定向；HTTP 仅显式放行字面回环。无 stdio 进程启动入口。
- 外部工具描述、只读 annotations 和返回文本均不构成本地授权，可能含提示注入。
- 配置为受限权限明文：Windows 当前用户 DACL，POSIX 目录 700/文件 600。不要提交配置。
- 已知凭据精确替换保护部分日志/结果/Session/Transcript；不保证抵御所有编码、分片或主动外泄。
- HTTP 请求超时的远端执行结果可能未知，不自动重试；断连不能撤销副作用。
- 会话恢复不重放工具；缺失结果补充未知占位符，不假定未执行。
- 不要分享 `.env`、用户配置、`.sessions`、`.memory`、`.transcripts`、任务输出或未经审查的日志。

doctor 只检查依赖与配置可解析性，不验证密钥、远端证书环境、权限策略完整性或目录可写性。
测试默认不访问外部服务或调用收费模型；真实评测必须单独授权并确定预算。

# 已知限制

1. 模型接口为 Anthropic Messages 兼容形式，不承诺任意服务商协议兼容。
2. MCP 支持 Streamable HTTP 与文本结果；不支持旧式 SSE 入口、OAuth 自动登录、多模态及 structuredContent。
3. MCP 配置不热加载，无自动重连；ask 不开放 MCP，chat 需明确连接与授权。
4. Worktree 隔离依赖 Git，不是文件系统/进程沙箱；无 Git 时不能使用这项隔离。
5. Session 恢复主消息快照，不恢复成员、Job、审批、读取版本；durable Cron 仅持久化定义。
6. 邮箱为 at-most-once 消费；处理失败后不自动重投。遗留 Task claim 需人工核验恢复。
7. 线程软停止和远端超时不能保证立即撤销已发生的副作用。
8. 工作目录与模型客户端是进程级状态；不支持同一进程同时嵌入多个独立工作区。
9. 本地 Prompt 缓存不是 Provider 缓存，不能据此宣称服务端缓存命中率。
10. 发布候选未提供完整编码任务基准与消融评测，不以单元测试通过率替代真实任务成功率。

仓库只包含产品与发布测试，不包含课程材料。发行包不安装测试和演示服务。
